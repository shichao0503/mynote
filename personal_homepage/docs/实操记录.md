## 遇到的问题与处理

### 命令行 Git 拉取失败

首次尝试 `git clone` 时，Windows TLS 后端报告凭据初始化错误；临时切换 TLS 后端的第二次尝试仍遇到连接提前结束。

处理：没有修改全局 Git 配置，也没有关闭 TLS 证书校验。改用已经连接的 GitHub 工具读取远程分支、生成文件树、创建提交并更新 `main`。这样保留原始提交，同时把页面与教程上传到仓库。

### 预览首次连接被拒绝

浏览器在本地服务启动前尝试打开预览，出现连接被拒绝。启动 `node scripts/serve.mjs` 后，重新打开预览地址即可。这个错误不代表页面代码有问题，要先确认服务是否在监听。
